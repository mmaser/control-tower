# Feedback and contributions

Tried Control Tower and something felt awkward? That is useful feedback, even if you cannot explain it in Git terms.

Open an issue using **Report a problem** or **Share feedback** in this repository's Issues tab. Include the Control Tower version, your app and surface (for example, Codex desktop or Claude Code CLI), what you asked it to do, and what happened instead.

A short fictional example is often enough. Remove company details, personal information, credentials, private links, and other people's chat content before posting. Avoid uploading entire conversations or Git inventories.

For a proposed change, explain which real problem it solves. Small, focused pull requests are welcome. Keep general coordination guidance separate from project-specific accounts, release commands, and preferences. If you change the Git helper, include a reproducible check in a temporary repository showing the affected behavior and that existing work stays untouched.

This is an occasional side project. Feedback will inform future versions, but there is no promised response time or release schedule.
